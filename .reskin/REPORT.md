# Reskin report — Receiva

Generated: 2026-11-10 (Asia/Shanghai) · Project: `website/` (Vue 3.5.13 + Vite 6)

The UI was rebuilt around **Abyss Liquidity** / **Terminal Console**; the original **sidebar-workspace** shell and palette were removed while the content contract stayed byte-for-byte intact.

| Field | Value |
|---|---|

`STYLE.md` holds the full token block and the candidate ranking; `style.json` is the machine copy.

Why this direction: the selector sampled the public frontends, scored every direction for perceptual
distance from the original accent (`#067a4e`) and ground (`#ffffff`), and chose Abyss Liquidity at
**130.7 ΔE** because it pairs with Terminal Console, a linear skeleton instead of the old
`sidebar-workspace` one. Nothing from Aave is reused: no logo, copy, code, imagery or brand name —
only palette family, typography mood, shape language, density and motion.

## 2. Skeleton — what changed structurally

| Region | Old | New |
|---|---|---|
| Chrome | floating command bar over a fixed 76 px icon rail | **fixed 30 px status strip** (dots, mark, scan line, glyphs) + per-route sticky command bar |
| Navigation | left icon rail, rotated labels | **left index column** on `/` and `/transparency`, **vertical command list** inside the app |
| Page head | oversized running head with a marginal standfirst | **record head** with a CSS-generated section number, mono label and hairline rule |
| Sections | numbered white plates on a light ground | **records** in a dark document column, separated by 1 px lines |
| Side data | right-hand card column | **sticky live rail**: token card, metric strip, live router balance |
| Hero | centred 3D vault filling the viewport | **hero record** with the scene inside a bordered "stage" plate (corner marks, stage bar, mono footnote) |
| 3D scene | full-viewport fixed canvas | fixed-height instrument plate; never drives layout |
| App routes | top bar + card stack + right chain card | **three-pane console**: command list · pane stack · "what the chain sees" instrument panel + bottom hint strip |
| Transparency | rail + runhead + tables in a doc column | **doc console**: index rail · numbered sections · sticky table headers |
| Mobile | collapsed text menu | index/nav become horizontal command strips; single-column records |

Landmarks were deliberately restructured to `header, nav, main, aside, footer` (the old run had
`nav, div[banner], main, aside, div[contentinfo], nav×3`), which is why landmark similarity sits at
0.375–0.5. Section numbers are generated by CSS counters, so no visible copy was added.

## 5. Accessibility & responsive results

- One `h1` per route, ordered heading hierarchy, native `header`/`nav`/`main`/`aside` landmarks,
  labelled complementary panel and command lists.
- Every control has an accessible name; the two amount inputs keep `aria-label="Amount"`.
- Contrast: body `#f4f7fa` on `#000` (19:1), muted `#8fa3b5` (8:1), faint `#8194a5` (6.7:1) —
  0 failures across 367 text nodes.
- Focus: global `:focus-visible` ring in the accent colour, verified by tab traversal.
- Motion: scan line, pulse and toast transitions sit behind `prefers-reduced-motion` guards.
- Responsive: 1180 px drops the live rail, 900 px stacks grids, 760 px turns the index/app nav into
  horizontal command strips, no document-level horizontal overflow at 390 px.

## 6. Known limitations

- `/pay/:recipient` is dynamic and skipped by the capture (needs a concrete recipient fixture); its
  component (`SendPane`) is covered through `/send`.
- The landed-address flourish inside the statement sheet is hidden: a scroll-synchronised capture
  caught it mid-reveal and the content contract forbids adding those address tokens. The reveal now
  reads through the sheet border instead.
- Section numbers are CSS counters, not text, to keep the content contract exact.
- The 3D vault keeps its WebGL scene, now inside a fixed-height instrument plate so it can never
  drive layout (a probe measured a 123k-px-tall mobile page before the plate height was pinned).
- The X/launch artwork (`twitter/*.png`) is not part of this Vue gate; it is re-rendered separately
  from `twitter/design/*.html`.
